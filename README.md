# UNIK

Site du stand mode (défilés, animations, créateurs). HTML/CSS/JS pur, sans framework.

## Lancer
Ouvrir `index.html` dans le navigateur.

## Ajouter du contenu
- Un évènement : `js/data/events.js`
- Un créateur : `js/data/creators.js`
- Les images : `assets/img/`

Un évènement passe tout seul de "À venir" à "Archives" selon sa date.
